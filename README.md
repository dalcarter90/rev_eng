# rev_eng

Reverse-engineering work, done with REA (https://rea.tools) and Ghidra.

- `docs/game-porting-process.md`: the step-by-step process for porting PC games
  to Windows and Linux, then Android and iPad.
- `docs/switch-re-pipeline.md`: extracting Switch titles and analyzing them
  with Ghidra headless.
- `games/_template/`: copy this to start a new game
  (`cp -r games/_template games/<game-name>`).
- `games/mhgu/`: Monster Hunter Generations Ultimate recompilation notes.
- `games/project8/`: contributing to Project8Recomp (testing plan, fixes).
- `docs/candidates.md`: Stage 0 findings for possible next games.
- `examples/`: REA practice examples.

Never commit game assets or original executables.
